Architecture

Built for real-world AI workloads

A streaming graph executor that orchestrates dozens of LLM calls with fault tolerance and provider flexibility.

Two-Phase Execution
Analysis phase builds the execution graph, then execution phase streams results — with checkpointing at every seam.
28-Node Streaming Graph
Dynamically constructed graph with 28 nodes — orchestrator, managers, workers, and synthesis — all communicating via streaming.
Real LLM Tool Calls
Powered by MiniMax M2.7 — every node makes actual LLM API calls with structured output parsing and tool result handling.
Checkpoint Fault Tolerance
Every seam boundary is a checkpoint. On failure, the graph resumes from the last successful node — no work is lost.
Free-Provider Fallback
Automatically falls back between MiniMax, Groq, OpenRouter, and NVIDIA endpoints — ensuring execution even under rate limits.
Real-Time Streaming
Token-by-token streaming output as workers complete. Watch the graph light up node by node during execution.
